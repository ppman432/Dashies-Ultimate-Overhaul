# Ceasefire Mechanics - Submod API (events)
#
# These are hidden, stable entry points intended for other mods to trigger.
# Scope conventions:
# - Start events: ROOT = receiver, FROM = initiator
# - Break/End events: ROOT = breaker/ender, FROM = other signatory
